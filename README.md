# OFFLINERICH

Monorepo root for **BIGBROTHER IPTV**.

## IPTV playlist panel

The owner panel lives in [`iptv-panel/`](./iptv-panel/).

```bash
cd iptv-panel
cp .env.example .env.local
npm install
npm run dev
```

See [`iptv-panel/README.md`](./iptv-panel/README.md) for full run instructions, playlist URLs, and daily refresh.
