How QR phishing asks for Unlimited Approve

A QR only opens a URL (often via link.trustwallet.com/open_url). Funds move only if you confirm a wallet popup. This page never hardcodes attacker payout addresses as the spender.

Safe test order
  1. Use a new Trust account with only dust (tiny BNB + tiny USDT on BSC).
  2. Scan 01-trust-deeplink-opens-example.com.png first — Trust should open example.com.
  3. Host this folder on HTTPS, regenerate QR with make_qr.py, scan that.
  4. Below: connect burner → try message sign first → optional tiny approve to your own spender.
  5. Revoke approvals and empty the burner when done.
