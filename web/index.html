Bulk wallets (local file)

Put up to hundreds of secrets in a local wallets.txt (one base58 key per line) and set WALLETS_FILE=./wallets.txt in .env. This UI will never accept pasted private keys — that pattern is how drain sites work.

Parallel burst fires many buys at once. It is a race, not an atomic lock: other traders can still land between your txs. Jito-style bundles only cover a handful of transactions, not 300.
